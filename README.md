# StockVision AI — Stock Market Forecasting & Backtesting Platform

Please navigate to the `stockvision-ai/` directory for the full project.

## Quick Launch

### Backend:
```powershell
cd stockvision-ai/backend
python -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
```

### Frontend:
```powershell
cd stockvision-ai/frontend
npm run dev -- --host 127.0.0.1 --port 5173
```

Open your browser at: **`http://127.0.0.1:5173/`**

For comprehensive project documentation, system architecture, methodology, and screenshots guidance, see [`stockvision-ai/README.md`](stockvision-ai/README.md).
